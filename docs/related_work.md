# Ближайшие работы: таблица для ревью

Отбор из локального литературного корпуса и дополнительных первоисточников.
Ссылки ведут на проверенные страницы. Это целевая подборка под текущую
постановку SGD/SGLD, а не исчерпывающий обзор. Черновик связного текста — в `paper.tex`.

**Рабочее позиционирование.** Ближайшие по замыслу источники покрывают
разные части сравнения: CNC и активные седла объясняют интерес к направлению
шума; matched-trace сравнение контролирует его суммарную величину;
SGLD-работы различают время достижения и качество риска. В нашем дизайне
предлагается наблюдать эти величины **в одном протоколе**, на конечном
оракульном бюджете. По этой подборке нельзя делать вывод «никто не изучал»;
для публикации потребуется адресный поиск эмпирических работ, близких по
совокупности факторов.
